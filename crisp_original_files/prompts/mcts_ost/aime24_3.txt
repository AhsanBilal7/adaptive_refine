# Question: 
How many 3-letter words can we make from the letters A, B, C, and D, if we are allowed to repeat letters, and we must use the letter A at least once? (Here, a word is an arbitrary sequence of letters.)
# Reasoning:
Step 1: Count all possible 3-letter words from A, B, C, and D. Each position has 4 choices, so total = 4^3 = 64.
Step 2: Count words with no A (only B, C, D). Each position has 3 choices, so total = 3^3 = 27.
Step 3: Subtract to get words with at least one A: 64 - 27 = 37.
Step 4: The answer is: \boxed{37}.

# Question:
In the diagram, square ABCD has sides of length 4, and triangle ABE is equilateral. Line segments BE and AC intersect at P. Determine the measure of angle BPC.
# Reasoning:
Step 1: Triangle ABE is equilateral, so angle ABE = 60°.
Step 2: Angle ABC = 90° (square), so angle PBC = 90° - 60° = 30°.
Step 3: Triangle ABC is right isosceles, so angle BCA = 45°.

# Question:
Find the positive real number(s) x such that (1/2)(3x^2 - 1) = (x^2 - 50x - 10)(x^2 + 25x + 5).
# Reasoning:
Step 1: Let a = x^2 - 50x - 10 and b = x^2 + 25x + 5.
Step 2: Then (1/2)(3x^2 - 1) = (a + 2b - 1)/2, so equation becomes (a + 2b - 1)/2 = ab.
Step 3: Multiply by 2: a + 2b - 1 = 2ab → rearrange: 0 = 2ab - a - 2b + 1.
Step 4: Factor: 0 = (a - 1)(2b - 1).
Step 5: Solve a - 1 = 0 → x^2 - 50x - 11 = 0 → positive root = 25 + 2√159.
Step 6: Solve 2b - 1 = 0 → 2x^2 + 50x + 9 = 0 (no positive root).
Step 7: The answer is: \boxed{25 + 2\sqrt{159}}.
